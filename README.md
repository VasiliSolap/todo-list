# Checkmate

A simple to-do list app built with React and Vite.

## Installation

You need Node.js and npm installed.

```bash
git clone https://github.com/VasiliSolap/todo-list.git
cd todo-list
npm install
```

## How to run

1. Start the server: `npm run dev`
2. Open the link from the terminal (usually http://localhost:5173) in your browser
